# Cheaptravels

Αναζήτηση πτήσεων από **Αθήνα (ATH)** προς επιλεγμένα αεροδρόμια ευρωπαϊκών χωρών, για τους επόμενους **180 ημέρες**, με **4 διανυκτερεύσεις** και συνολική τιμή με επιστροφή **κάτω από 100 € ανά ενήλικα**. Η διαμονή δεν περιλαμβάνεται. Άφιξη στον προορισμό την ημέρα αναχώρησης και αναχώρηση επιστροφής τέσσερις ημερολογιακές ημέρες αργότερα, σύμφωνα με τις τοπικές ημερομηνίες πτήσεων.

Χρησιμοποιεί το **Duffel Flights API v2** σε live mode. Η αρχική σύνδεση Amadeus αντικαταστάθηκε επειδή το Self-Service portal καταργήθηκε. Δεν καλύπτει όλες τις ευρωπαϊκές πόλεις ή όλες τις αεροπορικές εταιρείες· η διαθέσιμη κάλυψη εξαρτάται από τον πάροχο και τον λογαριασμό. Δεν αποτελεί εξαντλητική αναζήτηση της αγοράς. Οι τιμές και η διαθεσιμότητα αλλάζουν· οι αποσκευές χρειάζονται ξεχωριστό έλεγχο. Δεν πραγματοποιεί κρατήσεις.

## Απαιτήσεις

Python 3.12+, χωρίς εξωτερικές βιβλιοθήκες. Χρειάζεται λογαριασμός [Duffel](https://duffel.com/) με ενεργοποιημένη **live πρόσβαση**, νόμισμα προσφορών **EUR**, και live access token. Σύμφωνα με το [επίσημο SDK](https://github.com/duffelhq/duffel-api-javascript), τα tokens βρίσκονται στη σελίδα **Access tokens** του [dashboard](https://app.duffel.com/). Επιβεβαίωσε την επιλεξιμότητα του λογαριασμού, τους ισχύοντες όρους για αυτοματοποιημένη παρακολούθηση τιμών και τις χρεώσεις αναζητήσεων με το Duffel πριν ενεργοποιήσεις `--watch`. Δεν επαληθεύτηκαν η ενεργοποίηση λογαριασμού και η τρέχουσα τιμολόγηση· δεν έγινε αγορά ή συνδρομή.

Το πρόγραμμα αρνείται να στείλει test προσφορές ως πραγματικές ή να συγκρίνει άλλο νόμισμα με το όριο των 100 €. Αγνοεί ληγμένες προσφορές.

Ρύθμισε με ασφαλή εισαγωγή secrets στον host εκτέλεσης:

- `DUFFEL_ACCESS_TOKEN`
- `TELEGRAM_BOT_TOKEN` από το υπάρχον bot
- `TELEGRAM_CHAT_ID` για τη συνομιλία όπου θα στέλνονται οι προσφορές

Στείλε `/start` στο bot σου πριν την ενεργοποίηση. Μην αποθηκεύεις tokens στο repository και μην τα στέλνεις σε chat. Το πρόγραμμα διαβάζει τις μεταβλητές του process· δεν φορτώνει αυτόματα `.env`.

## Εκτέλεση

Από `/workspace/cheaptravels`:

```sh
python -m unittest -v
python cheaptravels.py --check-config
python cheaptravels.py --dry-run --limit 1  # μία αναζήτηση API, χωρίς Telegram
python -u cheaptravels.py --watch
```

Το `config.json` ρυθμίζει αεροδρόμια, ημερομηνίες, όριο τιμής και συχνότητα. `start_date`/`end_date` μπορούν να είναι ημερομηνίες ISO, αλλιώς το εύρος κυλά αυτόματα. Η επιστροφή πρέπει να βρίσκεται μέσα στο εύρος.

Η προεπιλογή εκτελεί έως **40 αναζητήσεις ανά ώρα**, προχωρώντας κυκλικά στους συνδυασμούς ημερομηνίας/προορισμού. Δεν ελέγχονται όλοι οι συνδυασμοί κάθε ώρα: με 36 προορισμούς ένας πλήρης κύκλος διαρκεί περίπου 7 ημέρες. Πρόκειται για έως 960 αναζητήσεις την ημέρα: μην ενεργοποιήσεις συνεχή αναζήτηση πριν ελέγξεις τις χρεώσεις και τα όρια του API. Το `--limit 1` περιορίζει τις αναζητήσεις κατά τον πρώτο έλεγχο. Τα αποτυχημένα αιτήματα επανεξετάζονται στον επόμενο κύκλο εκτέλεσης. Οι δοκιμές χρησιμοποιούν mock αποκρίσεις· δεν έχει επαληθευτεί ζωντανή σύνδεση χωρίς token και δικτυακή πρόσβαση.

Το `state/offers.sqlite3` διατηρεί το ιστορικό. Αποστέλλεται μία ειδοποίηση ανά συγκεκριμένο δρομολόγιο, ημερομηνίες και ώρες πτήσεων, ακόμη και αν αργότερα αλλάξει η τιμή. Η πρώτη εκτέλεση στέλνει όλες τις νέες επιλέξιμες προσφορές που βρίσκει. Διατήρησε αυτό το αρχείο σε μόνιμο δίσκο και τρέξε **μόνο ένα instance**. Μην το διαγράφεις για επανεκκίνηση. Μια διακοπή ακριβώς μετά την αποστολή και πριν την εγγραφή στο ιστορικό μπορεί να προκαλέσει επανάληψη· το Telegram δεν προσφέρει idempotency key για την αποστολή.

Για συνεχείς ειδοποιήσεις απαιτείται host που παραμένει ενεργός με supervisor (π.χ. systemd) και μόνιμο δίσκο. Ένα προσωρινό Codex task δεν εγγυάται λειτουργία 24/7. Εναλλακτικά ένας scheduler καλεί `python cheaptravels.py` κάθε ώρα, χωρίς επικαλυπτόμενες εκτελέσεις.

Απαραίτητη έξοδος HTTPS: `api.duffel.com`, `api.telegram.org`. Τα παλιά `AMADEUS_CLIENT_ID` και `AMADEUS_CLIENT_SECRET` δεν χρησιμοποιούνται και μπορούν να αφαιρεθούν από τις ρυθμίσεις του περιβάλλοντος.
