# Cheaptravels

Αναζήτηση πτήσεων από **Αθήνα (ATH)** προς επιλεγμένα αεροδρόμια ευρωπαϊκών χωρών, για τους επόμενους **180 ημέρες**, με **4 διανυκτερεύσεις** και συνολική τιμή με επιστροφή **κάτω από 100 € ανά ενήλικα**. Η διαμονή δεν περιλαμβάνεται. Άφιξη στον προορισμό την ημέρα αναχώρησης και αναχώρηση επιστροφής τέσσερις ημερολογιακές ημέρες αργότερα, σύμφωνα με τις τοπικές ημερομηνίες πτήσεων.

Χρησιμοποιεί το **production Amadeus Flight Offers Search API**. Δεν καλύπτει όλες τις ευρωπαϊκές πόλεις ή όλες τις αεροπορικές εταιρείες: ειδικά εταιρείες χαμηλού κόστους όπως Ryanair/easyJet μπορεί να απουσιάζουν. Δεν αποτελεί εξαντλητική αναζήτηση της αγοράς. Οι τιμές και η διαθεσιμότητα αλλάζουν· οι αποσκευές χρειάζονται ξεχωριστό έλεγχο. Δεν πραγματοποιεί κρατήσεις.

## Απαιτήσεις

Python 3.12+, χωρίς εξωτερικές βιβλιοθήκες. Δημιούργησε εφαρμογή στο Amadeus for Developers και ενεργοποίησε production πρόσβαση (ενδέχεται να απαιτεί στοιχεία χρέωσης). Το test API έχει περιορισμένα δοκιμαστικά δεδομένα και δεν χρησιμοποιείται για πραγματικές προσφορές.

Ρύθμισε με ασφαλή εισαγωγή secrets στον host εκτέλεσης:

- `AMADEUS_CLIENT_ID`
- `AMADEUS_CLIENT_SECRET`
- `TELEGRAM_BOT_TOKEN` από το υπάρχον bot
- `TELEGRAM_CHAT_ID` για τη συνομιλία όπου θα στέλνονται οι προσφορές

Στείλε `/start` στο bot σου πριν την ενεργοποίηση. Μην αποθηκεύεις tokens στο repository και μην τα στέλνεις σε chat. Το πρόγραμμα διαβάζει τις μεταβλητές του process· δεν φορτώνει αυτόματα `.env`.

## Εκτέλεση

Από `/workspace/cheaptravels`:

```sh
python -m unittest -v
python cheaptravels.py --check-config
python cheaptravels.py --dry-run  # πραγματικές αναζητήσεις API, χωρίς Telegram
python -u cheaptravels.py --watch
```

Το `config.json` ρυθμίζει αεροδρόμια, ημερομηνίες, όριο τιμής και συχνότητα. `start_date`/`end_date` μπορούν να είναι ημερομηνίες ISO, αλλιώς το εύρος κυλά αυτόματα. Η επιστροφή πρέπει να βρίσκεται μέσα στο εύρος.

Η προεπιλογή εκτελεί έως **40 αναζητήσεις ανά ώρα**, προχωρώντας κυκλικά στους συνδυασμούς ημερομηνίας/προορισμού. Δεν ελέγχονται όλοι οι συνδυασμοί κάθε ώρα: με 37 προορισμούς ένας πλήρης κύκλος διαρκεί περίπου 7 ημέρες. Αύξησε το `requests_per_scan` μόνο αφού ελέγξεις τις χρεώσεις και τα όρια του API. Τα αποτυχημένα αιτήματα επανεξετάζονται στον επόμενο κύκλο εκτέλεσης. Δεν έχει επαληθευτεί ζωντανή σύνδεση χωρίς τα κλειδιά.

Το `state/offers.sqlite3` διατηρεί το ιστορικό. Αποστέλλεται μία ειδοποίηση ανά συγκεκριμένο δρομολόγιο, ημερομηνίες και ώρες πτήσεων, ακόμη και αν αργότερα αλλάξει η τιμή. Η πρώτη εκτέλεση στέλνει όλες τις νέες επιλέξιμες προσφορές που βρίσκει. Διατήρησε αυτό το αρχείο σε μόνιμο δίσκο και τρέξε **μόνο ένα instance**. Μην το διαγράφεις για επανεκκίνηση. Μια διακοπή ακριβώς μετά την αποστολή και πριν την εγγραφή στο ιστορικό μπορεί να προκαλέσει επανάληψη· το Telegram δεν προσφέρει idempotency key για την αποστολή.

Για συνεχείς ειδοποιήσεις απαιτείται host που παραμένει ενεργός με supervisor (π.χ. systemd) και μόνιμο δίσκο. Ένα προσωρινό Codex task δεν εγγυάται λειτουργία 24/7. Εναλλακτικά ένας scheduler καλεί `python cheaptravels.py` κάθε ώρα, χωρίς επικαλυπτόμενες εκτελέσεις.

Απαραίτητη έξοδος HTTPS: `api.amadeus.com`, `api.telegram.org`.
